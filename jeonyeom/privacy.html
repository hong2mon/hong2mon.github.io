개인정보 처리 안내

적용일: 2026년 10월 20일 · 전염 채널 운영 도구

사용하는 정보와 목적

운영자가 Google OAuth로 승인한 경우, 채널 ID·채널명·업로드 영상 목록과 영상의 제목, 설명, 태그, 공개 상태, 처리 상태를 확인합니다. 운영자가 지정한 완성 영상과 메타데이터를 YouTube에 전송하고, 잘못된 채널 업로드와 중복 업로드를 막기 위해 결과를 기록합니다.

보관 위치와 공유

인증 토큰은 운영자의 PC에 별도로 저장합니다. 영상·업로드 기록도 운영자 PC에 저장하며 GitHub 공개 웹사이트에 게시하지 않습니다. 업로드를 위해 필요한 데이터만 Google 및 YouTube의 공식 API로 전송합니다. Google 계정 비밀번호는 이 도구가 수집하지 않습니다.

Google API로 받은 데이터는 광고, 판매, AI 모델 학습에 사용하지 않습니다. 데이터 사용 및 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

권한 철회와 삭제

운영자는 Google 계정 연결 관리에서 접근 권한을 철회할 수 있습니다. PC의 인증 파일과 업로드 기록은 운영자가 직접 삭제할 수 있습니다. YouTube에 업로드한 영상은 YouTube Studio에서 별도로 관리하거나 삭제합니다. 삭제되지 않은 로컬 기록은 중복 방지를 위해 보관됩니다.

Instagram 연결 시

운영자가 자신의 Instagram 프로페셔널 계정을 연결하는 경우, 계정 ID·사용자 이름·게시물 정보·게시 처리 상태를 확인하고 운영자가 지정한 영상과 문구를 Meta의 공식 API에 전송합니다. 인증 토큰과 작업 기록은 운영자의 PC에 보관하며 공개 웹사이트에 올리지 않습니다. 비밀번호·개인 메시지·연락처는 이 도구의 수집 대상이 아닙니다. 연결과 게시에는 각각 운영자의 승인이 필요합니다.

Instagram 데이터 삭제 안내

연결을 해제하려면 Instagram의 앱 및 웹사이트 관리에서 해당 앱의 권한을 철회한 뒤, 운영자 PC에 있는 Instagram 인증 파일과 작업 기록을 삭제합니다. 이미 게시한 릴스는 Instagram에서 별도로 삭제합니다. 이 안내 사이트는 개인용 운영 도구의 설명 페이지이며 방문자의 Instagram 데이터나 인증 정보를 받지 않습니다. 삭제에 도움이 필요하면 아래 문의 경로를 이용하되 공개 문의에 인증 정보나 개인정보를 올리지 마세요.

웹사이트와 외부 서비스

이 안내 사이트는 GitHub Pages에 호스팅되며 자체 분석 도구·광고·입력 폼을 사용하지 않습니다. 접속 시 GitHub가 처리하는 기술 정보에는 GitHub 개인정보 처리방침이 적용됩니다. Google 서비스에는 Google 개인정보처리방침이 적용되며, Instagram 연결 시 Meta가 처리하는 정보에는 Instagram 개인정보처리방침이 적용됩니다.
