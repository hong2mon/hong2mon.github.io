적용일: 2026년 10월 20일

전염 채널 업로드 도구는 채널 운영자 자신의 영상 게시를 보조하는 개인용 소프트웨어입니다. 일반 이용자의 계정을 수집하거나 대신 운영하는 서비스가 아닙니다.

업로드와 콘텐츠

운영자는 게시할 파일, 제목, 설명, 태그 및 공개 상태를 확인하고 업로드를 실행합니다. 콘텐츠의 권리와 YouTube 정책 준수 여부는 운영자가 확인합니다. API 처리 중 통신 오류나 플랫폼 제한이 생길 수 있으며, 접수 결과가 불명확할 때는 기존 업로드 결과를 확인한 뒤 진행합니다.

YouTube API

이 도구는 YouTube API 서비스를 사용합니다. 관련 사용에는 YouTube 서비스 약관 및 YouTube API 서비스 약관이 적용됩니다.
