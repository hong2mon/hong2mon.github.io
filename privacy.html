개인정보처리방침

시행일: 2026년 9월 14일 · 개정: 2026년 9월 25일(Meta 플랫폼 항목 추가)

"미친 설계 관리"(이하 "본 도구", 구 건축해부도 관리)는 채널 미친 설계(구 건축해부도)의 운영자가 본인의 유튜브 채널과 Instagram·Facebook·Threads 계정을 관리하기 위해 사용하는 개인용 소프트웨어입니다. 본 도구는 일반 사용자에게 배포되지 않으며, 운영자 본인의 계정으로만 사용됩니다.

1. 접근하는 정보

본 도구는 Google의 YouTube Data API 및 YouTube Analytics API를 통해 다음 정보에 접근합니다.

  • 운영자 채널의 영상 목록, 제목, 설명, 태그, 공개 상태, 예약 공개 시간
  • 운영자 채널의 조회수, 시청 시간, 구독자 변화 등 통계
  • 운영자 채널 영상에 달린 댓글

2. 이용 목적

  • 영상의 제목·설명·태그 수정 및 공개 예약 관리
  • 채널 통계 확인
  • 댓글 확인 및 답글 작성

3. 저장과 보관

Google 로그인 후 발급되는 인증 토큰은 운영자 본인의 컴퓨터에만 저장됩니다. 접근한 채널 데이터는 외부 서버로 전송되지 않으며, 제3자에게 제공·판매·공유되지 않습니다.

4. Google API 서비스 사용자 데이터 정책 준수

본 도구가 Google API로부터 받은 정보의 사용과 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

4-1. Meta 플랫폼(Instagram·Facebook·Threads)

본 도구는 Instagram API, Facebook Graph API, Threads API를 통해 운영자 본인의 Instagram 프로페셔널 계정(@michin.design), Facebook 페이지, Threads 계정에 한해 다음 정보에 접근합니다.

  • 운영자 계정의 게시물·릴스 게시(운영자가 만든 영상과 캡션)
  • 운영자 게시물에 달린 댓글 확인 및 운영자 명의의 답글 작성
  • 운영자 계정과 게시물의 통계(조회·도달·좋아요·저장·공유·팔로워 수)

댓글 작성자의 공개 사용자 이름과 댓글 내용은 운영자가 답글을 판단하는 용도로만 운영자 컴퓨터에서 확인하며, 외부로 전송·판매·공유하거나 광고·프로파일링에 쓰지 않습니다. 접근 토큰은 운영자 본인의 컴퓨터에만 저장됩니다.

4-2. 데이터 삭제 요청

본 도구가 보관하는 정보는 운영자 컴퓨터의 접근 토큰과 운영용 기록뿐입니다. 본인의 댓글 등 정보가 본 도구의 기록에서 삭제되기를 원하면 아래 이메일로 요청해 주세요. 요청을 받은 날부터 30일 안에 삭제하고 결과를 회신합니다. Instagram·Facebook 설정의 '앱 및 웹사이트'에서 본 도구의 접근을 언제든지 해제할 수도 있습니다.

5. 접근 권한 철회

Google 계정의 제3자 앱 액세스 권한 페이지에서 언제든지 본 도구의 접근 권한을 철회할 수 있습니다.
